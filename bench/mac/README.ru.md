# Замер Qwen3.8-27B на Mac: prefill и генерация на длинном контексте

Пакет повторяет на другой машине замер, сделанный на MacBook Pro M3 Max 128 ГБ для статьи о гибридном инференсе.
Модель, коммит llama.cpp, параметры сервера и скрипт замера те же, поэтому результаты можно сравнивать напрямую.
Подходит любой Mac на Apple Silicon с памятью от 48 ГБ.

## Что понадобится
- Mac на Apple Silicon с памятью от 48 ГБ; цель замера 64 ГБ.
- Около 55 ГБ свободного места: модель 19 ГБ, сборка llama.cpp около 1 ГБ, сохранённые слоты до 28 ГБ. Без 55 ГБ
  скрипт сам отключит замер сохранения слотов, тогда хватит 25 ГБ.
  Импорт слотов 260k/1M с GPU добавляет около 45 ГБ для оригиналов и до 36 ГБ для одной временной копии:
  всего около 136 ГБ с базовыми 55 ГБ (для одного 260k — около 73 ГБ: 55 + 9 + 9 ГБ).
- Xcode Command Line Tools, cmake, git, python3 версии 3.8 или новее. cmake ставится командой `brew install cmake`.
- Интернет: GitHub для исходников llama.cpp и Hugging Face для модели.
- Питание от сети и 3–5 часов, в которые машина не занята другой тяжёлой работой. Дольше всего идёт
  чтение контекста до 249 тысяч токенов. Замер параллельных агентов на 64k и 128k токенов можно пропустить,
  тогда выйдет на час меньше.

## Как запустить
Через агента: открой папку пакета в своей агентской среде (Claude Code, Codex или другой) и попроси: «Выполни
задачу из AGENT_PROMPT.md». Агент проверит машину, соберёт llama.cpp, скачает модель, проведёт замеры, упакует
результат и коротко расскажет, что получилось.

Вручную: `bash scripts/run-all.sh`.

## Что отправить
Архив `qwen27b-mac-bench-results-*.tar.gz` из папки пакета, тому, кто попросил провести замер. В нём:
- числа замеров и логи сервера;
- версии llama.cpp и модели;
- характеристики машины: чип, память, число ядер GPU, версия macOS.

Пути перед упаковкой заменяются метками. Имени компьютера, имени пользователя, серийного номера и файлов с диска
в нём нет. Тексты для замера генерируются
скриптом.

## Как остановить
Ctrl-C. Скрипты останавливают только свой llama-server, по сохранённому номеру процесса. Всё, что пакет создаёт,
лежит внутри его папки, в `work/` и `results/`. Чтобы убрать всё, достаточно удалить папку пакета.

## Импорт слотов с GPU (пакет 1.4.0)

GPU сохраняет файл с одним потоком. Шаги 56 и 57 читают его из `work/slots-import/`
или `SLOT_FROM`. Для сервера с `-np > 1` они проверяют формат и создают копию в
`work/slots-restream/`, меняя только число потоков и добавляя пустые потоки.
При переходе на меньшее число потоков копия создаётся заново. При `-np 1` сервер
читает оригинал. В `results/kit.log` записываются SHA-256 оригинала и копии.
Оригинал не меняется; временная копия удаляется при выходе, ошибке и обработанном
сигнале. Для неё нужно место размером с оригинал плюс `4 × (np − 1)` байт и запас
1 МиБ; если места нет, шаг сообщает о переходе на один поток с чтением оригинала напрямую.

Шаг 00 читает `lowpowermode` и `powermode` macOS 26+: значение 1 означает
энергосбережение, 0 и 2 — нет. В `system.json` поле `low_power_mode` равно 1 или 0,
только когда это следует из известного значения (`low_power_mode_status` "measured"). Если нет
обоих ключей или значение незнакомо набору, записывается null со статусом "unknown", а предупреждение
попадает в `results/kit.log`; строки pmset сохраняются в `low_power_mode_raw`.
Ограничения формата и команды инструментов перечислены
в английском `README.md`.
