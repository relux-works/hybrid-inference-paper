\section{Экономика}
\label{sec:economics}

\textbf{Две границы сравнения.} Решающее сравнение относится к самому дешёвому допущенному API
при тех же требованиях к контексту, доступности и формату задачи. На основной выделенной базе гибрид
не дешевле самого дешёвого API ни в одной оценимой измеренной точке Qwen.
Даже нулевая цена серверного prefill оставляет расходы клиента и обслуживания:
на уже имеющемся M5 Max это $2.52+5=7.52$ доллара на человека в месяц.
При лёгкой нагрузке 840 вызовов в месяц измеренный минимум Qwen v1 с долгими паузами даёт
около 3.03 доллара. Значит, уже эта часть расходов больше счёта API;
вывод ограничен указанной лёгкой нагрузкой, бесплатное вычисление не обнуляет остальные расходы.

% checker-site: v5d4-task-cost-bound
Цена вызова не является ценой выполненной работы. Профиль из 1.5 миллиона вызовов показывает интенсивность
и формы нагрузки, без измерения доли задач сильных облачных моделей, которые выполняет Qwen-27B.
Сравнения качества ниже сопоставляют варианты переноса одной модели; они не устанавливают её заменимость облачным моделям.
В журнальном срезе классы не выше Qwen по индексу модели, включая стандартное усилие рассуждения,
содержат $21935+238266=260201$ вызов: $260201/1530739=17.0\%$.
Их счёт $606.13+(4823.74\ldots5126.72)=5429.87\ldots5732.85$ доллара
при общем счёте $112543.74\ldots124462.94$; доля равна 4.6--4.8\%:
$100\times5429.87/112543.74=4.8\%$ и $100\times5732.85/124462.94=4.6\%$ на соответствующих границах оценки.
На более высокий класс моделей приходится $1248111/1530739=81.5\%$ вызовов и
$106836.72\ldots118452.94$ доллара, против $15061.07\ldots24456.49$ за те же токены
по тарифам Qwen3.8-27B (таблица~\ref{tab:owner}). Большая часть денег приходится на эти вызовы;
способность Qwen решать эти задачи в работе не проверена. Классы и счёт получены из журналов
и тарифов октября 2026 года; сравнение не зависит от серверного движка и допуска API.
Классификация по индексу не измеряет, какие задачи Qwen выполнит успешно.

\textbf{Основная база: выделенный сервер команды.} Клиент уже принадлежит пользователю: M5 Max 64~ГБ,
измерения с записанным обычным приоритетом. Строк экономики M3 Max нет; его выигрыш в статье измерен во времени.
Сервером служит купленный RTX PRO 6000 с vLLM FP8 в офисе; канал 125~МБ/с и RTT 1~мс заданы как предположения.
Рекуррентное состояние на проводе по умолчанию bf16, 78\,446\,592 байта; контроль f32 соседний.
Резидентное состояние остаётся f32; сокращение байтов передачи не уменьшает память сессии и не ускоряет импорт в модели.

\textbf{Граница профиля.} Общая измеренная лестница содержит формы 10\,885 из 39\,904 вызовов,
$10885/39904=27.28\%$ числа вызовов, без утверждения о доле токенов или объёма работы.
Выбранные формы приведены к 840 / 3360 / 10\,500 вызовам на человека в месяц при доле открытой модели 20\%.
Лёгкая нагрузка равна 200 вызовам в день, средняя 800; эти нагрузки заданы как сценарии. Тяжёлая, 2500 в день,
есть интенсивность владельца. Полная необусловленная смесь не оценена.
Интерполяция клиентских скоростей, вытеснение и глубокий импорт остаются моделями.
Пакетная генерация PRO 6000 измерена на 16\,384 / 65\,536 / 164\,000 / 256\,000 токенах;
между опорами интерполируется время на токен с учётом резидентного пакета.
За пределами диапазона PRO 6000 и для B300 генерация остаётся модельной: аренда B300 не запустила контейнер.

\textbf{Цена установленного узла.} Покупка \$30\,000, срок 4 года, остаток 20\%, поддержка 2\% в год;
мощность 0.9~кВт. При PUE 1.3, 730 часах в месяце, офисной доле мощности 0.5 и \$0.15 за кВт\,ч
месячная цена равна 614.06 доллара. Плата за офисное размещение принята нулевой.
Эта цена взимается за весь установленный узел, включая простой.
Вариант аренды: $2.20\times730=1606$ долларов в месяц, предполагаемый канал 112.5~МБ/с, RTT 400~мс;
передача оплачивается по \$5 за десятичный ТБ, хранение отдельно.

\textbf{Занятость рядом с ценой.} Рабочая занятость делит расчётную работу GPU на установленное время
восьмичасового рабочего дня; календарная использует 730 часов в месяц. Это занятость выделенного ресурса с учётом
инструментов и конкуренции, без утверждения об аппаратной загрузке SM. Целочисленный парк гибрида достаточен,
минимальность парка не доказана. Все денежные суммы ниже относятся к компоненту открытой модели при одинаковых формах вызовов.

\textbf{Чувствительность парка, отдельный расчёт.} Четыре узла удерживают 200 копий,
по 57 на узел: 54 на NVMe и 3 в GPU. Округление $\lceil200/57\rceil=4$ задаёт хранение,
минимальность вычислительного парка из этой границы не следует.
Расширенный NVMe при одном / двух / четырёх узлах даёт 19.95 / 32.38 / 57.23 доллара на человека в месяц,
тёплая RAM 23.47 / 39.42 / 71.31. Это отдельная чувствительность с неизмеренными восстановлением,
ценой расширения, потоком запросов и очередью; таблица~\ref{tab:r22-dedicated50} остаётся на прежней базе.
Один узел даёт выгодный оффлоад только общему профилю при $s=20\%$ и лёгкой нагрузке;
остальные допустимые строки одного узла отражают хранение и локальные вычисления после отказа очереди.
Подробные условия и отказы приведены в приложении~\ref{app:engine25-26}.

\textbf{Небольшая команда.} При средней нагрузке и пяти людях гибрид стоит \$130.33 на человека в месяц
при рабочей/календарной занятости 6.19/1.42\%; свой кластер \$245.62 при 32.12/7.39\%.
При лёгкой нагрузке и трёх людях гибрид \$212.21 при 0.98/0.22\%, свой кластер \$204.69 при 10.12/2.33\%.
При лёгкой нагрузке и 10 или 20 людях гибрид \$68.93 при 2.93/0.67\%, свой кластер \$61.41 при 39.55/9.10\%.
Доплата гибрида в этих лёгких случаях равна $2.52+5=7.52$ доллара на человека.

\textbf{Цена простоя.} Отношение цены медианного API при условной доле кэша 98.1\% к цене гибрида
у команды из 50 человек равно 0.088 на выделенной базе против 0.313 на общей при лёгкой нагрузке;
при тяжёлой 1.097 против 1.701. Средняя нагрузка даёт 0.351 против 0.934.
Общая база есть дополнительный предел распределённых расходов занятого поставщика prefill;
авторы также ведут такой общий сервис. Цитируемые отношения общей базы используют непрерывную занятость 70\%,
а цена при полной занятости 100\% служит отдельной нижней оценкой.
Отличаются также тариф покупки и аренды, хранение, промахи резидентности и пакетирование;
разность не выделяет причинный эффект одного простоя. Ночные агенты могут поднять занятость,
их непрерывный спрос остаётся предположением.

\textbf{Уже имеющийся или новый Mac.} Покупка M5 Max 64~ГБ добавляет \$69.05 на человека в месяц;
при 50 людях общая цена \$125.69, рабочая/календарная занятость остаётся 3.61/0.83\%, 14.46/3.33\%
и 45.17/10.40\% для лёгкой, средней и тяжёлой нагрузки соответственно.
На купленном офисном сервере пересечение со своим кластером при средней нагрузке сдвигается с 5 до 34 человек;
при тяжёлой остаётся с 2. Пересечение с медианным API при условных 98.1\% кэша исчезает.

\textbf{Одна чувствительность тяжёлой нагрузки.} Если перенести всю генерацию на свой vLLM-сервер,
при 50 людях цена составит \$331.59 на человека в месяц при рабочей/календарной занятости 66.61/15.33\%.
Это одна чувствительность к размещению генерации; второй Mac не предполагается.

\textbf{Глубокий профиль Claude.} Граница нулевого оффлоада на M5 Max вынесена в начало статьи; в расчётном экспорте доля оффлоада и занятость 0.00\%.
Пересечения цен этого профиля относятся к локальной работе Mac с простаивающим парком резидентности;
эти пересечения исключены из выводов о гибридном оффлоаде.
Для лёгкой нагрузки этого профиля на арендованном PRO 6000 с каналом 112.5~МБ/с, RTT 400~мс,
при уже имеющемся M5 Max 64~ГБ и доле открытой модели 20\% пересечение со своим кластером
сдвинулось с 87 до 73 человек, до конца проверки в 500 человек. Доля оффлоада остаётся нулевой.

\textbf{Три точки кэша и допуск API.} Для каждого расписания отдельно сравниваются отсутствие кэша,

\textbf{Пример тарифа одного поставщика.} Снимок OpenRouter от 2026-10-29 для \texttt{qwen/qwen3.8-27b}
в точке условного кэша 98.1\% даёт минимум у Chutes: вход \$0.039, выход \$1.25, чтение кэша \$0.0039 за миллион токенов,

клиент гибрида использует Q4\_K\_M, сервер vLLM FP8. Сравнения качества в статье относятся к собственным
вариантам гибрида; сравнения качества с API не проводились.
Допуск исключает только недостаточный контекст, отсутствие заявленного кэширования и доступность ниже 95\%
в общем выбранном окне. Низкую измеренную долю кэша учитываем в цене; отсутствие попаданий само по себе не исключает поставщика.
Для снимка используется одна метрика за последние сутки у всех поставщиков; точные границы интервала не сохранены.

Текущее измеренное окно применяется к опробованным поставщикам: доступность ниже 95\% исключает запись.
Для поставщиков без попыток сохранён явно обозначенный суточный снимок; отсутствующая доступность непроверена.
Старое исследовательское резюме GLM не сохранило деклараций кэша и доступности, его тарифы не служат заменой измерений.

\textbf{Сопоставимый набор цен.} Измеренная медиана v1 \$12.55 выше \$8.68 без кэша,
потому что первый набор содержит 11 оценимых поставщиков, второй 15;

допущенной измеренной короткоинтервальной точки Qwen нет, поэтому сравнение смещено в пользу гибрида.

\subsection{Закрытый контур}
\label{sec:closed-contour}
Если данные должны оставаться внутри организации, гибрид сравнивается с внутренним инференсом.
Сначала организация выбирает класс модели, затем способ исполнения.
Модели облачной весовой категории, от сотен миллиардов до триллионов параметров, требуют собственного серверного кластера:
в память рассматриваемых клиентов такая модель не помещается, гибрид к этому классу неприменим.
Многоузловой B300 для этого класса задан как направление конфигурации без измерения.

Для среднего класса рассматриваются плотные модели около 30 млрд параметров и MoE около 300 млрд.
Свой кластер выполняет prefill и генерацию; в гибриде сервер читает новые токены, клиент генерирует.
Для плотной Qwen3.8-27B клиент M5 Max 64~ГБ измерен; вариант 128~ГБ задаётся как конфигурация.
Для MoE GLM-5.3-Flash предполагается Mac Studio M5 Ultra с 256--512~ГБ;
две B300 на серверную реплику заданы как расчётная конфигурация, без замера этой реплики.
Скорость Studio и серверный prefill GLM не измерены.
Если клиентов нет, их покупка входит в цену гибрида.
