## Session hosting

All new hosting numbers are budget/policy estimates, not provider quotes:
four retained copies/person for a full month, RAM$0.50/decimal-GB-month,
HBM$8 and NVMe$0.10 alternatives,50GB/s effective PCIe,100GB/s RAM or 7GB/s NVMe.
HBM performs no cold migration. Capacity is assumed provisionable at the stated
linear incremental pool cost. This does not claim that RAM/NVMe is inside the
prefill GPU SKU or free because the GPU's purchase budget has been paid.

Cold copies read the old prefix and spill updated context on every client-served
shadow call. Time is conservatively reserved as occupied GPU time; overlap and
hot-cache savings are not assumed. Only reload on offloaded calls is foreground
wait. Retained copies for API/turbo-only requests are not charged again as hybrid
storage. Storage estimates use mean end-of-call bytes rather than session traces.
Four copies/person are not derived from 116-call normalization groups.
